# Sahay Setu — Hyperlocal Emergency Resource Coordination Platform

A ward/RWA-level MERN application that lets residents pre-register emergency
resources and, during a localized flood or crisis, matches real-time needs to
nearby available resources with live volunteer dispatch.

## Tech Stack
- **Frontend:** React 18 (PWA), Leaflet.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Real-time:** Socket.IO
- **Database:** MongoDB Atlas (2dsphere geospatial indexes), Mongoose
- **Auth:** JWT, phone OTP, RBAC (resident / volunteer / admin)
